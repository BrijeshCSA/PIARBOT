# VK PIAR BOT

Бот для рекламных (пиар) рассылок во все чаты/беседы, где присутствует бот.
Оплата через внутренний баланс, подтверждение владельцем, роли, статистика.

## Возможности

- 📢 **Пиары с интервалом 1–60 минут** — от 1000₽ (раз в минуту) до 50₽ (раз в час)
- 💰 **Баланс** — пополняется после подтверждения оплаты владельцем
- 🤝 **Ручное подтверждение** — владелец/зам пишет `/piar_ok <номер>`
- 🎁 **Подписка на сообщество** — бонус 100₽ (один раз)
- 🎭 **Роли** — owner / deputy / admin / moderator
- 📊 **Статистика** — пользователи, чаты, активные пиары, суммы
- 🔁 **Авторассылка** — фоновый поток рассылает во все беседы бота

## Команды

| Команда | Описание |
|---|---|
| `/start` | Меню + кнопки |
| `/пиар` | Создать пиар |
| `/моипиары` | Мои пиары |
| `/активныепиары` | Все активные пиары |
| `/баланс` | Проверить баланс |
| `/подписка` | Бонус 100₽ за подписку |
| `/cancel` | Отменить текущее действие |
| `/piar_ok <номер>` | Подтвердить оплату (только owner/deputy) |
| `/role <id> <роль>` | Выдать роль (owner — deputy; owner/deputy — admin/moderator) |
| `/roles` `/staff` | Список команды |
| `/стата` | Статистика |

## Быстрый старт

### 1. Подготовка сообщества VK

1. Создайте или откройте группу.
2. **Управление → Работа с API → Ключи доступа → Создать ключ**
   - Отметьте ✅ **Сообщения сообщества**
   - Скопируйте `vk1.a.…` — это `VK_TOKEN`
3. **Управление → Работа с API → Long Poll API**
   - Включить **Bots Long Poll API**
   - Версия API ≥ 5.131
   - В типах событий отметить `Message New`, `Message Event`
4. **Управление → Сообщения**
   - Включить «Сообщения сообщества»
5. Узнайте свой `user_id` (из `vk.com/idXXXXX`) — это `OWNER_ID`

### 2. Запуск локально

```bash
cp .env.example .env
# отредактируйте .env — впишите свои значения

pip install -r requirements.txt

python check.py   # проверка конфига
python bot.py     # запуск
